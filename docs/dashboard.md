# 网页看板

## 定位

网页看板位于 `web/`，只负责展示 Backend 返回的数据，不读取数仓、标准化中间数据或服务器文件，也不执行估算和 AI 分析。

## 本地启动

先在 `127.0.0.1:8000` 启动 Backend，再运行：

```bash
cd web
npm ci
npm run dev
```

Vite 把 `/api` 转发到本地 Backend。生产环境中，同一路径由 Nginx 转发到 `jd-competitor-analysis-backend:8000`。

## 加载流程

```text
打开网页
  → GET /api/product-pairs
  → 默认选择最新日报对应的本品和日期
  → 按竞品分别 GET /api/reports/{report_id}，同屏展示所选周期报告
  → 按竞品 GET /api/reports/trends，共享最近七天的指标趋势图
```

商品对接口返回日、周、月各粒度的最新报告和报告数量。最新报告条目的 `path` 由 Backend 生成，例如：

```json
{
  "period_key": "day:2026-08-18",
  "path": "/api/reports/报告ID"
}
```

条目使用 `start_date` 和 `end_date` 表示周期范围，并包含本品、竞品的 SPU 与商品名。Web 默认打开最新日报，报告选择和页面会话缓存均使用唯一的 `report_id`。

日期选择器展开、切换月份或年份时调用：

```text
GET /api/reports/periods?self_spu=...&competitor_spu=...&granularity=day&context=2026-08
```

接口只返回当前日历上下文的轻量报告条目和可导航上下文。选择具体日、周或月后，Web 再按 `report_id` 加载对应完整报告。趋势图调用 `/api/reports/trends`，响应仅包含周期元数据和成交金额、访客数、成交转化率、成交客单价，不读取五张分析表及 AI 内容。

日历使用同一本品各竞品可用周期的并集。同一日期范围的报告并行读取，各竞品的成功、失败和缺失状态独立展示。分析及存储仍以商品对为单位。

报告也可按周期范围读取：

```text
GET /api/reports/{granularity}/{start_date}/{end_date}
```

日报的 `start_date` 与 `end_date` 相同；自然周的日期范围为周一至周日。本品 SPU 的 SKU 构成通过页面的“查看 SKU”入口展示，数据来自 `GET /api/reports/{report_id}/skus`。弹窗固定展示 `spu_id`、`sku_id`、`barcode_69`、`product_name` 和 `specification` 五个字段，并使用生成报告时的数据集快照。

## 展示约束

1. 本品为真实值，竞品为准真实估算值。指标卡同时展示本品和各竞品，差距按竞品分别呈现。
2. 缺失值显示为 `-`，数值零正常显示。
3. 页面只展示 Backend 返回的 AI 结果，不拼接或回退到模板建议。
4. 缺失模块保持空状态，并展示对应风险说明。
5. 已加载报告可以在当前页面会话中按 `report_id` 缓存。
6. 页头按本品 SPU 分组，宽屏一行展示本品与一至两个竞品，右侧提供周期与 SKU 操作；竞品按导航顺序标记为“竞品 1”“竞品 2”，同时展示。单竞品只展示两个商品块，小屏换行。点击本品名称、ID、箭头或空白区域打开选择菜单；只有商品主图跳转京东，菜单内的主图随选项一起切换本品。商品数量以已有报告为准。
7. 其他周期的完整报告只在用户选择对应周期后加载。
8. 切换本品保留已选日期范围及日、周、月粒度。某竞品对应周期没有报告时仅该侧展示空状态，其他竞品保持可读；全部无报告时展示页面空状态。日历保留所选周期，不自动跳到最新报告。
9. 商品列表来自已有报告，不同步完整飞书目录。快速切换时只展示最新选择的报告和趋势，旧请求不能覆盖当前页面；无报告及加载失败时不展示上一商品的指标、建议或 SKU 快照。
10. 优缺点与 AI 建议按竞品独立展示，结论详情逐点列出，弱点在上。趋势共用时间轴，各竞品缺失值独立断线。
11. 差距来源的重点数据按竞品分栏：竞品 1 在左、竞品 2 在右，每栏优势在上、劣势在下，优势卡片使用柔和红色与浅红背景，劣势卡片使用绿色与浅绿背景；单竞品展示一栏，窄屏按竞品顺序上下排列。缺失重点数据保留对应竞品的空状态。
12. 差距来源使用共享表格，按完整渠道路径、关键词、画像维度与名称对齐全部记录。默认展示全部指标；一排指标按钮可切换规模、金额、转化率和占比，窄屏可横向滚动按钮。名称列固定在最左侧，蓝色表头的计算列排在原始数据列之前。各商品对原有差距保持原值；本品值若口径不同则按竞品分别标明。

差距来源表格的放大窗口居中显示，宽高均为浏览器视口的 90%，表格填满窗口内容区。可点击收起按钮、遮罩或按 `Esc` 关闭。

## 商品选择交互测试

运行前端开发服务后，访问 `/test/product-navigation.html` 可执行隔离的浏览器回归测试。页面使用模拟 API，验证本品分组、单／双竞品、商品链接独立性、同周期空报告、快速切换响应隔离、键盘操作及 320、900、1280 像素布局，不读取或修改业务数据。
