# 运营分析 SOP

依据：2026-09-14《京东自营竞品看板分析与运营优化 SOP》运营访谈版。

## 数据与触发

分别对比本品与各竞品，使用相同周期、指标和渠道层级。核心汇总与渠道明细可能口径不同；真实值、区间估算值分别标识，估算比较注明“按估算值对比”。空白、未披露、未上榜不是零；缺失或口径异常标记待核查，不据此断定经营原因。日周月采用各自后端聚合结果，日均使用自然周期天数。

| 指标 | 触发 | 动作 |
| --- | --- | --- |
| 渠道访客 | 本品小于竞品 | 对有明确动作的渠道生成建议 |
| 关键词访客 | 双方 Top 10 并集中，本品同词访客小于竞品 | 关键词投放／竞品品牌追击 |
| 成交转化率 | 竞品高至少 2 个百分点 | 核查库存、价格、SKU 图卖点 |
| 性别、年龄、省份成交占比 | 竞品高至少 3 个百分点 | 对应人群／地区投放 |
| 广告点击率 | 竞品高至少 1 个百分点 | 优化广告创意图 |
| 成交客单价 | 展示数值与差距 | 说明可能与价格不同有关，不单独生成动作 |

百分点采用绝对差，不是相对百分比。成交占比不等于人群转化率，广告点击数不代替点击率，整体转化率不代替渠道或同词转化率，客单价不代替同规格到手价。

## 渠道与关键词

搜索下拆关键词；百亿相关频道检查在线状态并提报专享价，其他频道核查可用活动；购物车使用红包及数坊购物车营销；商品增加店内展示和关联导流；店铺增加展示；活动增加会场资源；内容增加种草直播；首页增加核心楼层、首焦资源；站外增加 CPS 提报及佣金。推荐、我的京东、商详间接分发、游戏、其他仅展示访客差距，不直接生成动作。父子同一问题合并，优先可操作最细层级。

本品与每个竞品分别按访客取 Top 10，并集去重最多 20 词。未进入对方 Top 10 的词从完整明细查找，仍缺失则待核查，不填零。Top 词合计不当作全部搜索流量。普通词增加投放，明确竞品品牌词进入品牌追击；品牌不明时先核查。

## 核查前提

同词访客不足且转化差距达到门槛时，先检查库存、断码并处理，再核查可比到手价并处理，确认两项无问题后增加投放。库存问题补货；价格偏高提报百亿专享价／投放数坊暗券。未核查时明确“待核查库存与价格”。SKU 图卖点优化独立提出，不作为增加投放的强制前置条件。

画像性别、年龄、省份独立比较；相似竞品达到门槛后直接提出对应投放建议，无需另设适配确认。其他维度只展示差距。

## 建议与复查

建议包含对标商品、周期、对象、双方数值、差距、估算标识、动作前提及复查指标。符合条件即输出，不限定来源数量，不为凑数量生成建议。每个商品对单独生成，同一对标内重复对象及父子同一问题合并；不同竞品的建议在看板分别展示。

实际执行后一周复查，不按建议生成日起算；对照执行前后可比一周并观察竞品变化。活动、大促、缺失导致不可比时标明影响，不将所有变化归因于动作。

| 动作 | 复查指标 |
| --- | --- |
| 关键词／品牌追击 | 同词访客、差距，有数据时同词转化率 |
| 渠道资源／购物车／CPS | 对应渠道访客、差距、转化率、成交金额 |
| 补货 | 库存、断码、转化率 |
| 价格 | 实际到手价差距、转化率 |
| SKU 图 | 商品转化率及对标差距 |
| 人群／地区 | 对应成交占比及差距，有数据时成交人数 |
| 广告图 | 广告点击率及差距 |

复查观察改善、持平或恶化，不承诺提升幅度，不将触发门槛作为提升目标。周复盘关注动作与到期复查，月复盘用当月独立数据汇总持续差距及复查表现。

## 系统范围

AI 按运行提示词执行触发判断、Top 10 筛选、动作匹配和文案生成，后端执行结构校验。阈值尚不属于独立的确定性规则引擎。人工执行日期、状态、自动到期复查及跨竞品动作合并不在当前实现内；复查文本作为运营操作指引，不表示系统已记录执行。

提示词用于后续 AI 请求，既有报告保持已保存的分析；基础数据 `rebuild` 保留 AI 内容，不更新历史建议。`reanalyze --date YYYY-MM-DD` 读取该日期已有日报事实，按当前提示词强制重跑 AI；命令示例见 [数仓与手动命令](warehouse.md#只重跑指定日期的-ai)。
